# 時間の拘束と溜まった用事：提案

2026-09-29。当初の提案を保存した文書。ユーザー承認後、質問名を「時間を動かしにくい用事」に変更し、0.1.12で実装。以下は検討時の記録。

目的は仕事の有無ではなく、自分の都合では中断・後回しにできない時間のまとまりから、現在まで／現在からの距離を記録すること。仕事・家事・育児・介護・授業などを対象とする。家事だけの新しい質問は作らない。

1. 「仕事・家事などが終わったのは？」今日／昨日／2日前／3〜6日前／1〜2週間前／もっと前。「今やっている」「特にない」を付ける。
2. 「次に仕事・家事などがあるのは？」今日／明日／2日後／3〜6日後／1〜2週間後／もっと先。「未定」「予定なし」を付ける。前問が今やっているなら省略。
3. 「やることは、どれくらい溜まっている？」なし／少し／そこそこ／多い／とても多い。縦5行で、箱が積み上がるアイコン。個別の用事、種類、件数、文字入力は不要。つらさではなく溜まり具合を質問する。

前後の時期は従来同様に暦日で引き継げる。溜まり具合はその時点の状態なので自動補完しない。既存の仕事だけを答えた記録を、家事等を含む回答へ読み替えない。実装時には保存項目を区別する。

日単位では今日の朝と今、今晩と今の距離は区別できない。現在の6択を保つ案にはこの限界がある。短時間の家事が連続する場合には、終わった区切りの判断が必要になる点も試用で確認する。

## 根拠と仮説の区別

反すうと気分の関係は研究されているが、用事からの距離をそのまま反すう・抑うつ・自殺リスクへ置換できる根拠ではない。忙しいほど良いという判定は設けない。

- 日常場面の気分と反すうを反復測定した研究： https://pubmed.ncbi.nlm.nih.gov/35389688/
- NIMHは自殺の複数の危険因子とストレス要因を説明している。「暇な人ほど自殺しやすい」という単純な前提は置かない： https://www.nimh.nih.gov/health/publications/suicide-faq
